  background="muted"
>
  <GuideSplit>
    <GuideInfoCard eyebrow="The prayer structure" title="One decade = one mystery">
      Each decade is one Our Father, ten Hail Marys and one Glory Be while meditating a single mystery. The Joyful,
      Sorrowful, Glorious and Luminous mysteries each contain exactly five decades, so a 5-decade rosary completes one
      full set in a single piece.
    </GuideInfoCard>
    <GuideInfoCard eyebrow="Church practice" title="One set a day is the standard">
      For the daily Rosary, the Church asks for one set of five decades — not the full fifteen or twenty. The 15-decade
      rosary is the complete set for longer prayer sessions and is rarely carried by ordinary believers for daily use.
    </GuideInfoCard>
  </GuideSplit>
</GuideSection>

<GuideSection eyebrow="3 · Church-standardized history" title="A format standardized for centuries" background="muted">
  <GuideSplit>
    <GuideInfoCard eyebrow="1569" title="Approved as the standard unit">
      In 1569, Pope Pius V formally approved the five-decade rosary as the standard unit for a single prayer session.
      The format then spread through Catholic regions worldwide — Latin America, North America and Europe all follow
      this same physical standard.
    </GuideInfoCard>
    <GuideInfoCard eyebrow="2002" title="Still five decades today">
      When the Luminous mysteries were added in 2002, the Church did not change the physical rosary. Believers continue
      to use the 5-decade rosary and simply choose one set of five mysteries to meditate each day.
    </GuideInfoCard>
  </GuideSplit>
</GuideSection>
